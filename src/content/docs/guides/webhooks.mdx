Lunaz sends a signed POST request to your endpoint when an invoice, swap, withdrawal or plan changes. Each account has one webhook URL and one signing secret.

## Set up the endpoint

<Steps>

1. Open the webhooks page in the dashboard.

2. Enter the URL of your endpoint.

3. Copy the signing secret.

4. Send a test delivery.

5. Make sure that your endpoint returns a 2xx status.

</Steps>

To change the secret, rotate it on the same page. The old secret stops working at once. See [Webhooks API](../../api/webhooks/) for the request format.

## Event types

| Type | When |
| --- | --- |
| `invoice.paid` | The invoice is `paid`. |
| `invoice.underpaid` | The invoice expired with a payment that is too small. |
| `swap.refunded` | 1Click refunded a swap. The invoice stays `pending`. |
| `swap.failed` | A swap failed. The invoice stays `pending`. |
| `swap.incomplete_deposit` | The buyer deposited less than the quoted amount. The invoice stays `pending`. |
| `withdrawal.updated` | The status of a withdrawal changed. |
| `plan.updated` | The plan of your account changed. |
| `test` | You sent a test delivery. |

## Verify the signature

Each request has an `X-Lunaz-Signature` header. The value is the hex HMAC-SHA256 of the raw request body. The key is your webhook secret.

:::caution
VERIFY THE SIGNATURE ON THE RAW BODY BEFORE YOU PARSE THE JSON. IF YOU PARSE FIRST, THE BYTES CAN CHANGE AND THE CHECK FAILS.
:::

Compare the values in constant time. Reject the request if they differ.

<Tabs>
<TabItem label="Node.js">

```js title="verify.js"
import crypto from "node:crypto";

export function verify(rawBody, signature, secret) {
  const expected = crypto
    .createHmac("sha256", secret)
    .update(rawBody)
    .digest("hex");
  const a = Buffer.from(expected);
  const b = Buffer.from(signature ?? "");
  return a.length === b.length && crypto.timingSafeEqual(a, b);
}
```

</TabItem>
<TabItem label="Python">

```python title="verify.py"
import hashlib
import hmac


def verify(raw_body: bytes, signature: str, secret: str) -> bool:
    expected = hmac.new(secret.encode(), raw_body, hashlib.sha256).hexdigest()
    return hmac.compare_digest(expected, signature or "")
```

</TabItem>
<TabItem label="Go">

```go title="verify.go"
package main

import (
	"crypto/hmac"
	"crypto/sha256"
	"encoding/hex"
)

func verify(rawBody []byte, signature, secret string) bool {
	mac := hmac.New(sha256.New, []byte(secret))
	mac.Write(rawBody)
	expected := hex.EncodeToString(mac.Sum(nil))
	return hmac.Equal([]byte(expected), []byte(signature))
}
```

## Respond and retry

Return a 2xx status within 5 seconds. Lunaz treats any other status, and any network error, as a failure.

A failed delivery is retried after 10 s, 60 s and 300 s. This makes 4 attempts in total. After the last attempt Lunaz stops.

Use the delivery log, or read the invoice with the API, to find a missed event.

Your endpoint can receive the same event more than once. Use the `invoice_id` to ignore a repeat.

## Delivery log

Lunaz logs every attempt. The dashboard shows the log on the webhooks page.

Each row has the invoice ID, the event type, the URL, the HTTP status code, an error text, the attempt number and the time.
